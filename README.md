## 🚀 Главный проект — MIMAS

<p align="center">
  <a href="https://github.com/fiskarik/mimas"><img src="assets/mimas-card.svg" width="100%" alt="MIMAS — голосовое AI-интервью для найма в рознице" /></a>
</p>

<p align="center">
  <a href="https://mimas.onrender.com"><img src="https://img.shields.io/badge/site-mimas.onrender.com-2d6a4f?style=for-the-badge&logo=render&logoColor=white" alt="сайт" /></a>
  <a href="https://github.com/fiskarik/mimas"><img src="https://img.shields.io/github/stars/fiskarik/mimas?style=for-the-badge&color=40916c&logo=github&label=stars" alt="звёзды MIMAS" /></a>
  <a href="https://github.com/fiskarik/mimas/commits/main"><img src="https://img.shields.io/github/last-commit/fiskarik/mimas?style=for-the-badge&color=52b788&label=last%20commit" alt="последний коммит" /></a>
  <a href="https://github.com/fiskarik/mimas/blob/main/LICENSE"><img src="https://img.shields.io/badge/license-PolyForm%20NC-74c69d?style=for-the-badge" alt="лицензия" /></a>
</p>

Кандидат за 10 минут отвечает голосом на вопросы о рабочих ситуациях, а работодатель получает отчёт с баллами и цитатами из ответов.

- 🎙 **Голосовое интервью** — нужен только микрофон, камера по желанию
- 📋 **Прозрачная оценка** — каждый балл подтверждён точной цитатой; акцент, грамотность и уверенность голоса не оцениваются
- 👤 **Решение принимает человек** — AI помогает с первичным отбором, но не нанимает
